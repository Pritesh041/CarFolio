# Functional Requirements

## Collection

Users can:

- Add a car
- Edit a car
- Delete a car
- Duplicate a car
- Upload photos
- Record purchase price
- Record purchase date
- Record condition
- Record quantity

## Valuation

Users can:

- See total collection value
- See total amount invested
- See estimated gain/loss
- View value history
- View most valuable models

## Showcase

Users can:

- Create a showcase
- Select cars
- Add cover image
- Write description
- Publish showcase
- Share showcase publicly

## Marketplace

Users can:

- List a model for sale
- Set asking price
- Upload photos
- Receive offers
- Mark as sold

## Wishlist

Users can:

- Add models
- Set target price
- Set priority
- Track availability
