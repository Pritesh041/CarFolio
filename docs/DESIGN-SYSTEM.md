# Carfolio Design System

## Design Personality

Premium
Modern
Automotive
Minimal
Collector-focused
Technology-driven

## Visual Inspiration

- Luxury automotive websites
- Modern fintech dashboards
- Premium collector platforms

Do not copy any specific brand or website.

## Theme

Primary:
Graphite
Charcoal
Off-white
Neutral gray

Accent:
Racing / electric green

## Border Radius

Cards: 16px
Buttons: 12px
Inputs: 10px

## Typography

Headings:
Bold modern sans-serif

Body:
Clean neutral sans-serif

Numbers:
Large / highly readable

## UI Principles

1. Photography is important.
2. Numbers should be visually prominent.
3. Avoid visual clutter.
4. Use whitespace.
5. Avoid excessive gradients.
6. Avoid excessive glassmorphism.
7. Avoid generic admin dashboard styling.
